## HTTP Methods

### `curl`

Curl is useful for piping responses directly into something. In comparison to wget, which is just for get and saving those requests, and pipes outputs directly into the stdout.

### `wget`

Useful for running HTTP GET methods. Useful commands include:

```bash
# just get the server headers

wget --server-response --spider <URL> 

# Explicitly name the output file

wget -O catalogue.zip <URL>

# Respect content headers

wget --content-disposition <URL>
```

## AWS CLI

Login to aws through the portal of the org account, i.e. `https://XXXXXXXX.awsapps.com/start/#/`. Manage secrets by selecting the account and role, to then search for the secrets manager (you may have to change region for this). Modify the account settings within the account profile created in `~/.aws/config`

```yml
[profile bods-nonprod]
sso_account_id = 000000000000  # 12 digit id
sso_role_name = AdministratorAccess  # role
region = eu-west-2
sso_start_url = https://XXXXXXXXX.awsapps.com/start
sso_region = eu-west-2
```

Not always required, but you may need the [session-manager-plugin](https://docs.aws.amazon.com/systems-manager/latest/userguide/session-manager-working-with-install-plugin.html).

### `aws sso login`

Redirects you to a login page to grant your machine valid access.

```bash
aws sso login --profile bods-nonprod
```

### `aws configure sso`

Allows you to configure a new account (easier to update config)

## `aws ssm start-session`

Usually called with a number of arguments to set up the local tunnel, such as:

```bash
--region eu-west-2
--target "i-XXXXXXXXXXXXXXXXXX"
--document-name AWS-StartPortForwardingSessionToRemoteHost
--parameters
    host="env-dev.XXXXXXXXX.eu-west-2.rds.amazonaws.com",
    portNumber="XXXX",
    localPortNumber="XXXXX"
--profile env-nonprod
```

- `--target` can be found in the aws console (EC2>Instances>Instance-ID)
- `--document-name` is for defining what type of session to begin
- `--parameters host` defines the host rds database name, can be found in the aws console under Aurora and RDS
- `--profile` as defined by you within the config

## Python

### `uv`

Added python venv tracking via the following. Useful for tracking my main venv for general work.

```bash
uv pip freeze > requirements.txt && uv pip compile requirements.txt -o .pyvenv.lock
```

### `uv init <package-name>`

inits a package with name <package-name>. Will also create a '.venv' in that directory.

### `uv run main.py`

runs a file with the current '.venv'.

### `uv add pandas` | `uv pip <pip-commands>`

Adds a dependency to the current project (tracks by directory).

## `vim`

Your favourite cli editor.

`pacman -Sg vim-plugins` - check plugins available. NerdTree is a particular favourite.

This is all you really need for a vimrc:

```vim
" Colorscheme
:colorscheme catppuccin

" Start NERDTree and put the cursor back in the other window.
autocmd VimEnter * NERDTree | wincmd p

" Syntax highlighting
:filetype plugin on
:syntax on
```

You may need to use the following hack to get the clipboard to work on arch btw:

```vim
" Get the text into the clipboard on yank
augroup ExplicitX11ClipboardSync
  autocmd!
  autocmd TextYankPost * call s:SyncExplicitRegister()
augroup END
function! s:SyncExplicitRegister() abort
  let l:reg = v:event.regname
  let l:text = v:event.regcontents->join("\n")
  if l:reg == '*'
    call system("echo -n " . shellescape(l:text) . " | xsel --input --clipboard")
  elseif l:reg == '+'
    call system("echo -n " . shellescape(l:text) . " | xsel --input --clipboard")
  endif
endfunction
```
